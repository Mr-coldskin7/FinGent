## 1. 目标（按优先级）

1. **语料有价值**：AI 本身已经知道的通用金融知识没有检索价值。优先接入模型不知道的、可溯源的数据。
2. **可测量**：用确定性指标（检索命中、引用有效率、拒答正确率）说明效果，而不是只给一个印象分。
3. **可部署**：嵌入与生成都可走云端，不依赖某台机器上的本地模型。
4. **可视化**：检索过程与引用要能在前端展示（思维链 + 原文段落 + 评测面板）。

## 2. 关于 RAGAS：要不要用？

**结论：现阶段不需要，作为可选的第二层指标。**

- RAGAS 本身只是一个 pip 库，难点不在库，而在它的指标依赖 **LLM judge**：评分随 judge 模型、提示词、温度变化，不可复现，跨运行不可比。
- 40–50 道题的样本下，LLM-judge 分数的置信区间很宽，单个数字说服力有限。
- 更有价值的先是**确定性指标**：
  - 检索：hit@k、MRR（需要每题标注标准答案所在的 chunk，标注一次即可反复用）；
  - 引用：引用的 id 是否都在本次检索结果中（代码校验，零成本）；
  - 拒答：超出语料范围的题是否正确回答"资料不足"。
- 在这些基础上，再用 RAGAS 的 faithfulness 作为补充，并**固定 judge 模型与版本**，把配置一起记录在评测产物里。

## 3. 语料方案

### 3.1 第一批（推荐）

- **SEC 10-K / 10-Q**：3–4 只美股（如 NVDA、MSFT、AAPL），约 20 份。按章节切分（Item 1A 风险因素、Item 7 MD&A 等），元数据带 ticker、财年、章节、原文 URL、accession 号。
- **项目自己的分析历史**：来自 `memory` 库，每条记录含当时的结论、投票、理由与后续验证结果。这是"个性化"的来源，也是项目独有的数据。
- **新闻**：来自现有的 bocha / 新闻源，带发布时间戳，供舆情 agent 使用。

### 3.2 暂不做

- A 股财报（akshare 数据杂乱，需要单独清洗）。
- PDF 财报与扫描件：需要 OCR 或多模态解析，成本明显更高，留作后续。
- 9141 条通用问答：建议移出 RAG 语料；如需保留，只作为"术语词典"类的小集合。

### 3.3 切分与元数据

- 按章节 + 段落切分，目标长度 300–600 字，相邻 chunk 有少量重叠。
- 每个 chunk 有稳定 id（`{ticker}:{accession}:{section}:{n}`），便于引用与评测。
- 元数据统一：`ticker, doc_type, fiscal_period, section, source_url, published_at`。

## 4. 存储与嵌入

- **嵌入接口**：统一为 OpenAI 兼容的 `embeddings` 调用，默认走云端；本地 sentence-transformers 作为可选实现，通过环境变量切换。
- **待决策的 key**：DashScope（`text-embedding-v3/v4`）或 OpenAI（`text-embedding-3-small`）。当前 `QIANWEN_API_KEY` 不可用，需要确认。
- **向量库**：Chroma 本地持久化目录（不进 git）；在 `.gitignore` 中忽略，去掉 `RAG/rag_db` 与 `RAG/models` 的 LFS 追踪。
- **版本记录**：每次建库写入 `manifest.json`（嵌入模型名、维度、切分参数、语料哈希、建库时间）。换模型必须重建，不能混用。

## 5. 检索与护栏

- 先按 `ticker` 过滤，再做向量检索；可选加 BM25 做混合检索（语料小，收益待测）。
- **相似度阈值**：低于阈值时返回 `insufficient`，agent 必须回答"资料不足"，不得编造。
- **引用约束**：回答中的事实陈述必须带证据 id（如 `[E3]`）；生成后做代码校验，引用的 id 必须出现在本次检索结果中，否则判为违规并重试或降级。
- **可选的重排**：先不做，等基线数字出来再决定。

## 6. 评测

- **黄金集**：约 50 题。30 题有标准答案所在 chunk；10 题需要跨文档；10 题超出语料范围（测拒答）。
- **标注方式**：由 LLM 从 chunk 生成候选问题，人工筛选与修正。标注文件版本化。
- **指标**：hit@1/3/5、MRR；引用有效率；拒答正确率；延迟 p50/p95。
- **报告**：写入 `Eval/rag/<timestamp>/report.json`，并接入现有「评测中心」页面。
- **诚实标注**：样本量与置信区间（Wilson 或 bootstrap）必须和数字一起展示。

## 7. 前端与可视化（演示亮点）

- 思维链展示检索动作："检索 NVDA 10-K · 风险因素 → 命中 3 段，最高相似度 0.82"。
- 回答中的 `[E3]` 可点击，展开原文段落与 SEC 链接。
- 评测面板新增 RAG 区块：命中率、引用有效率、拒答率、样本量。
- 财报可视化：关键财务指标的时间序列图（从 10-K/10-Q 表格解析），与检索结果并排展示。这一项依赖表格解析，工作量需单独评估。
